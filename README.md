# ImageRouter hosted API

A simple, unified API for image and video generation models. Compatible with OpenAI SDK and servers 130+ models.

Try it for free on [ImageRouter](https://imagerouter.io)

For API reference, see the [Documentation](https://docs.imagerouter.io)
